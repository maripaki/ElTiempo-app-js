## App del Tiempo

Esta es una mini-aplicación web desarrollada desde cero para consultar el clima actual de cualquier ciudad del mundo en tiempo real. 

## Tecnologías utilizadas

 **HTML5**: Estructura visual de la interfaz.
 **CSS3**: Estilos, diseño limpio y maquetación de tarjetas.
 **JavaScript (ES6+)**: Lógica de la aplicación, control de eventos del DOM y peticiones asíncronas (`fetch`) para consumir una API externa.
 **OpenWeatherMap API**: Fuente de datos meteorológicos en tiempo real.

## Aprendizaje

Durante el desarrollo he practicado el uso de funciones asíncronas (async/await) y la gestión de peticiones HTTP mediante la API nativa fetch, aprendiendo a procesar respuestas en formato JSON y a manipular dinámicamente el DOM para mostrar la información en tiempo real.
Proyecto realizado como práctica de desarrollo frontend.
